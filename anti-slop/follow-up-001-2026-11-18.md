# Tindak lanjut audit UI

Lingkup: temuan 1, 2, dan 3 dari audit percakapan, disetujui untuk dieksekusi. Temuan 4 dan 5 tidak diubah. Identitas visual, tata letak, font, aset, dan konten yang ada dipertahankan.

## Perubahan dan alasan

1. **R-25 / R-34:** `.error` menggunakan `--danger-text` agar mengikuti tema, bukan merah tetap. Pada render browser, kontras pesan/modal menjadi 6,51:1 / 7,37:1 untuk tema terang dan 6,23:1 / 7,61:1 untuk tema gelap.
2. **R-32:** outline global mendukung token `--focus-ring`; sidebar desktop dan menu mobile memakai warna terang yang sudah ada pada palet sidebar. Kontras outline terhadap sidebar menjadi 8,39:1 pada kedua tema.
3. **R-03 / C-4:** pemilihan filter status mengaktifkan kolom Kanban yang sesuai. Mengganti kolom menyelaraskan filter status yang sedang aktif, tetapi tidak mengganti filter "Semua".

Implementasi: `app/style.css` dan `app/page.tsx`.

## Bukti verifikasi

- Sebelum perbaikan: 5 tes gagal karena masalah kontras dan ketidaksinkronan filter; 4 tes lainnya lulus.
- Setelah perbaikan: `npm test` lulus seluruh 10 tes Playwright.
- `npm run build` lulus kompilasi produksi, pemeriksaan tipe, dan pembuatan halaman statis.
- Pemeriksaan browser memakai Microsoft Edge/Chromium headless, viewport desktop 1280x900 dan mobile 390x844. Tes Kanban mobile menggunakan input sentuh sintetis; tidak ada klaim pengujian perangkat fisik.
- Screenshot akhir diperiksa untuk pesan error gelap, fokus sidebar terang, dan Kanban mobile. Screenshot tersimpan di `test-results/`, yang diabaikan oleh git.
- Detector Impeccable pada dua file implementasi menghasilkan 10 peringatan `overused-font` untuk font Plus Jakarta Sans yang sudah digunakan sebelumnya. Peringatan ini tidak dianggap bukti cacat desain dan tidak diubah di luar lingkup.

## Delivery Gate: lingkup temuan 1–3

- **R-25 / R-34 PASS:** pesan error halaman dan modal memenuhi 4,5:1 pada kedua tema; hasil ukur di atas.
- **R-32 PASS:** navigasi Tab memfokuskan tombol To-do dengan outline 8,39:1 pada desktop dan menu mobile; Escape menutup menu.
- **R-03 / C-4 PASS:** ketiga filter status menampilkan kolom beserta tugas yang sesuai pada viewport mobile; penggantian kolom menyelaraskan filter spesifik, sedangkan "Semua" tetap aktif; tidak ada overflow horizontal pada skenario tersebut.
- **R-35 PASS:** build berhasil; daftar interaksi yang diuji tercatat di bawah. Smoke test tidak menemukan `pageerror` maupun pesan console bertipe error.
- **R-31 PASS:** setiap perubahan memiliki alasan pada bagian pertama; tidak ada perubahan palet umum, komposisi, tipografi, atau motion.

## Interaksi yang diuji

- Tambah proyek, judul berisi spasi, Simpan: menampilkan validasi; Escape: menutup dialog.
- Tab pada sidebar desktop dan menu mobile: indikator fokus terlihat; Escape: menutup menu mobile.
- Filter Dikerjakan, Selesai, dan Belum Mulai pada ponsel: kolom dan tugas yang sesuai terlihat.
- Pemilih kolom: menyelaraskan filter spesifik dan mempertahankan filter Semua.
- Toggle tema: mengubah atribut tema ke gelap dan kembali terang.
- Tutup/Buka sidebar: mengganti keadaan sidebar.
- Tambah proyek, Simpan, buka detail, Edit, Batal, Buka Kanban proyek: alur lokal berjalan.
- Tampilan Daftar, filter status, pencarian tanpa hasil, Hapus pencarian, Semua: hasil tugas sesuai input.
- Tambah tugas, ubah status, Edit, Simpan, Hapus, Batal, Hapus terkonfirmasi: data lokal dan tampilan diperbarui.
- Tampilan Kanban desktop: ketiga kolom terlihat.
- Tambah request, Jadikan to-do, Simpan, buka hasil konversi: tugas hasil konversi dapat diedit; Escape menutup dialog.
- Masuk / Buat akun, Buat akun, Buka ruang kerja lokal: menuju halaman yang sesuai dan menampilkan pemberitahuan akun belum aktif.

## Batasan

Gate di atas hanya mencakup perbaikan yang disetujui, bukan sertifikasi seluruh aplikasi atau kepatuhan WCAG menyeluruh. Firebase, pengiriman autentikasi, seluruh variasi data, dan perangkat fisik tidak diuji. Temuan 4 (pesan hapus proyek mode Firebase) dan 5 (target sentuh lain) masih terbuka. Tidak ada skor Lighthouse atau Core Web Vitals yang diukur.
